# USP ikony VAPP — Tabler

Ctyri ikony pro USP pruh. Vsechny z Tableru, kontrakt shodny s `Ikony.dc.html`:
`viewBox 0 0 24 24`, `stroke-width 2`, `linecap/linejoin round`, `fill none`, `currentColor`.

| USP | ikona | dnes |
|---|---|---|
| 35 let zkusenosti | `award` | `clock` |
| Sklad dilu | `building-warehouse` | `package` |
| Rychla expedice | `rocket` | `truck` |
| Autorizovany servis | `tool` | `shield-check` |

Zadna ze ctyr neni v `Ikony.dc.html` — doplnit vsechny.

## Sestihranny klic

V Tableru **neni**. Sada nema imbus, sroubovak ani ockovy klic — jedine naradi
je `tool` (nastavitelny klic). Nejblizsi sestihran je `hexagon`, coz je holy
sestiuhelnik bez naradoveho kontextu (v `alternativy/` k posouzeni).

## Alternativy (`alternativy/`)

| soubor | k cemu |
|---|---|
| `military-award` | 35 let — vavrinovy odznak misto medaile |
| `certificate` | 35 let — duraz na doklad misto oceneni |
| `settings` | servis — ozubene kolo misto klice |
| `hexagon` | servis — holy sestiuhelnik, jedina sestihranna ikona v sade |
| `truck-delivery` | expedice — konkretni doprava misto metafory rakety |
| `building-store` | sklad — prodejna misto skladove haly |
